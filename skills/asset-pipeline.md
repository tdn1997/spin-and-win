# Asset Pipeline

## Priority
1. Use assets already in `res://assets/`.
2. If something is missing, use free assets only.
3. Preferred sources:
   - itch.io free assets
   - kenney.nl
   - opengameart.org

## External Assets
- Store downloaded files under `res://assets/external/`.
- Do not overwrite original local assets.
- Use clear filenames.
- Record source URL, license, and usage in `res://llm-wiki/assets.md`.

## Current Assets
- Slot machine frames and symbols are under `res://assets/Slot Machine/`.
- The current version does not download external assets.
- The `777` symbol is rendered as text so no extra image is required.
