# Project Overview

`spin-and-win` is a simple portrait-only mobile slot machine game built for Godot 4.x.

The game supports Android and iOS only. It is designed around touch input, large buttons, responsive `Control` layouts, and a small scene-based architecture.

## Current Playable Loop
- Open Main Menu.
- Tap Play.
- Tap Spin.
- Coins decrease by bet.
- Three reels animate and stop with staggered timing.
- The game evaluates the result and awards coins when applicable.
- Settings can toggle sound/music and reset coins.
