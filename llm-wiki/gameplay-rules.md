# Gameplay Rules

## Defaults
- Starting coins: `1000`
- Bet: `10`
- Reels: `3`
- Symbol count: `5`

## Symbols
- Four image symbols from local assets.
- One text-rendered `777` jackpot symbol.

## Payout Table
- Jackpot: `777 / 777 / 777` pays `bet * 50`.
- Big win: any three matching symbols pays `bet * 10`.
- Small win: any two matching symbols pays `bet * 2`.
- No match pays `0`.

## Spin Restrictions
- Player must have enough coins.
- Player cannot spin while reels are currently spinning.
